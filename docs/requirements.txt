# Documentation-only dependencies.

# Upper bounds are deliberate. Sphinx 9 tightened ambiguous Python cross-reference
# resolution, and both CI and RTD build on Python 3.11+, where floor-only pins resolve
# to the newest release rather than the validated one. Pin to the major versions this
# site is actually built and reviewed against; raise the ceilings in a commit that
# re-runs the -W build. `sphinx-rtd-theme` needs no ceiling of its own -- it declares
# `sphinx<10,>=6`, so the resolver always installs a Sphinx the theme supports. That range
# is NOT what keeps Sphinx 9 out; it admits it. Only the explicit `<9` below does, so do
# not drop that pin on the theory that the theme already covers it.
sphinx>=7.2,<9
sphinx-rtd-theme>=2.0
myst-parser>=2.0,<5

# `jaxptpolypol.desi_priors` and `jaxptpolypol.priors` do a module-level `import yaml` and
# are NOT mocked, so autodoc needs PyYAML present. It arrives transitively via myst-parser
# today; pinned explicitly so raising that ceiling cannot silently break autodoc.
pyyaml

# Light scientific deps: imported for real so autodoc can execute module-level
# constants. The heavy / non-PyPI stack (ps_1loop_jax, candl, clipy, candl_data,
# cosmopower_jax, blackjax, quadax) is mocked in conf.py instead.
numpy
scipy
jax
matplotlib
